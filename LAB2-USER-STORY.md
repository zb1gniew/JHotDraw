# User Story - Delete Selected Figures

# User Story: 

As a drawing application user, I want to delete selected figures from the canvas, so that I can remove unwanted elements without having to clear the entire drawing.

Acceptance Criteria:

- The user triggers "Delete" from the Edit menu or presses the Delete key
- Every selected figure is removed from the canvas
- The action is undoable
- If no figures are selected, nothing happens
